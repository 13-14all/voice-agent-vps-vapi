LEDGER SNAPSHOT SUMMARY — 2026-08-28

## Vision Summary
Vapi.ai-specific sibling of voice-agent-vps: one core engine, per-business
personality/voice/knowledge, telephony/STT/TTS delegated entirely to Vapi.
Two routing modes supported (static per-business assistant, or dynamic
number-based routing via Vapi's `assistant-request` event).

## Architecture Summary
Vapi → OpenAI-compatible Custom LLM endpoint (`/vapi/chat/completions`) →
hybrid Ollama/cloud LLM (RAG-augmented via Postgres+pgvector) → back to Vapi
for TTS/playback. `end-of-call-report` webhook feeds the live-caller
training loop. `app/core/reply_engine.py` is shared, unchanged, with the
Retell edition.

## Progress Summary
Forked from voice-agent-vps (Retell edition) v2. Replaced the Retell Custom
LLM websocket + call_analyzed webhook with Vapi's OpenAI-compatible
chat-completions endpoint + end-of-call-report/assistant-request server
events. All three training loops (knowledge ingestion, agent-vs-agent
simulation, live-caller feedback) ported over unchanged in spirit, adapted
to Vapi's payload shapes.
